Presentations repo containing folders for all presentations, including various versions of the same presentation given at different Meetups, SQL Saturdays and other conferences Scripts related to the presentation topic are also provided.  

1. "Tame Your Workday with Modern SQL Server Features" is the presentation previously entitled, "Modern SQL Server Features that make life better." This is a presentation designed to introduce features in modern SQL Server. The information is NOT an in-depth review of any one particular feature. The introduction will allow attendees to familiarize themselves with a wide range of features in modern, supported versions of SQL Server, with the goal being to enable technologists to further explore those features in their own environment and deploy these features as they make sense.

2. "Buttons Dials and Levers" addresses the meaning of common SQL Server settings, what their defaults are, and recommends better settings. The presentation empowers you to assess your environment's settings with confidence.

3. "Query Store" contains presentations on thge usefulness of Query Store for everyday troubleshooting, configuration settings, and a custom script to perform Before/After comparisons of performance using Query Store data.


4. "Four Focus Points In a New DBA Role" is a presentation I gave at PASS Summit 2022 online. The focus is providing a guided plan for those first days and weeks in a new role. When you switch companies, or get promoted, and are now responsible for SQL Server, you need a plan. This presentation provides that plan.
